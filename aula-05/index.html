Perguntas Frequentes

O que é Flexbox?

Flexbox é um modelo de layout do CSS que organiza itens em uma única direção (linha ou coluna), facilitando alinhamento e distribuição de espaço entre eles.

Para que servem as media queries?

Media queries aplicam estilos diferentes conforme características da tela, como largura ou orientação, permitindo criar layouts responsivos que se adaptam a desktop, tablet e celular.

Qual a diferença entre flex-grow e flex-basis?

flex-basis define o tamanho inicial de um item antes de o espaço sobrar ser distribuído; flex-grow define quanto desse espaço extra cada item deve receber, em proporção aos demais.

É possível reordenar itens sem mudar o HTML?

Sim. A propriedade order permite mudar a posição visual de um item flex sem alterar sua posição no código HTML, muito usado em media queries para reorganizar layouts.
