jQuery vs. JavaScript puro

Esconder um elemento

vanilla: el.style.display = "none";
jQuery:  $(el).hide();

Ouvir um clique

vanilla: el.addEventListener("click", fn);
jQuery:  $(el).on("click", fn);

Buscar dados de uma API

vanilla: fetch(url).then(r => r.json());
jQuery:  $.getJSON(url, dados => { ... });
