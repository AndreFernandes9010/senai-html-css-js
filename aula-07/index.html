Introdução ao Flexbox

O Flexbox é um modelo de layout do CSS que organiza itens em uma única direção (linha ou coluna), distribuindo espaço e alinhando elementos de forma flexível, mesmo quando o tamanho deles é desconhecido ou dinâmico.

Combinado com media queries, o Flexbox permite criar layouts responsivos: a mesma marcação HTML se reorganiza automaticamente conforme a largura da tela muda, sem a necessidade de duplicar conteúdo para cada dispositivo.

Neste exercício, o container principal (conteudo-wrapper) e o rodapé (footer) usam display: flex para alinhar seus filhos lado a lado no desktop e, através de media queries, alteram flex-direction e order para se adaptar a telas menores.
